

### 다른 컴퓨터에서 이어서 실습하는 순서

1. **현재 컴퓨터에서 GitHub에 업로드(`git push`)**
2. **다른 컴퓨터에서 저장소 클론(`git clone`) 후 프로젝트 폴더로 이동**
3. **다른 컴퓨터의 OrbStack에서 `Ubuntu 22.04` 머신(예: `cody-ubuntu`) 생성 후 접속**
   ```bash
   # 프로젝트 폴더 위치에서 우분투 접속 (우분투의 현재 위치가 자동으로 이 프로젝트 폴더가 됨)
   orb -m cody-ubuntu -u root
   ```
4. **우분투 안에서 복구 스크립트 1줄 실행**
   ```bash
   sudo bash etc/restore_up_to_step2.sh
   ```
   * 이 명령어 한 줄만 실행하면 패키지 설치 → SSH `20022` 포트 및 `root` 차단 → `UFW` 방화벽 활성화 → 3개 계정/2개 그룹 생성 → 폴더 권한(`2770`) 및 ACL(`setfacl`) 설정 → 검증 결과 출력까지 **약 20초 만에 지금 상태와 100% 똑같이 자동 복구**됩니다.
5. **복구 완료 직후 [B4-1-Practice-Guide.md의 Step 3] 부터 이어서 진행**
   * ⚠️ **참고 1**: 다른 컴퓨터에서 Step 3-1(파일 복사)을 진행할 때는 `/Users/...` 경로 대신 현재 프로젝트 폴더 기준 상대 경로(`sudo cp ./etc/agent-app/agent-app-linux-...`)를 쓰거나, 다른 컴퓨터의 맥 계정명 경로로 맞춰서 복사하시면 됩니다.
   * ⚠️ **참고 2 (민감정보 안내)**: GitHub에 올리실 때 [B4-1-Practice-Guide.md] 문서 안의 예시 경로에도 현재 맥 폴더명(`/Users/.../...`)이 7곳 포함되어 있으니, 만약 가이드 문서도 함께 GitHub에 공개로 올리실 예정이라면 이 부분도 마스킹하거나 상대 경로로 바꿔 드릴 수 있습니다. 필요하시면 말씀해 주세요!
